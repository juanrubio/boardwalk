# Boardwalk

**Boardwalk** is a proposed terminal-first way to file, edit, and visualize GitHub Projects work without opening a browser.

This repository currently contains the product requirements document and the accepted architecture and specification decisions; implementation has not started yet.

- [Product Requirements Document](PRD.md)
- [Architecture decisions](docs/decisions/) — ADR 0001: Go (Final); ADR 0002: GitHub API via `go-gh` (Final); ADR 0003: noun-first commands (Final); ADR 0004: three-board fixtures (Final); ADR 0005: user-only alias config (Final); ADR 0006: full TUI in MVP (Final); ADR 0007: Cobra + Charm stack (Final); ADR 0008: TOML config (Final); ADR 0009: bare JSON + exit codes (Final); ADR 0010: upfront auth scopes (Final)
- [Specifications](docs/specs/) — [TUI specification](docs/specs/tui.md) and [CLI specification](docs/specs/cli.md): all sections settled and accepted (Final)
